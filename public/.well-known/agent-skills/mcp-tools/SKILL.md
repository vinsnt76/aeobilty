# Skill: Connect to AEObility MCP Tools

## What This Skill Does

Enables Model Context Protocol (MCP) clients to query AEObility tools, brand consensus entities, and knowledge hub nodes.

## MCP Server Endpoint

`https://aeobility.com.au/api/mcp`

## Available Tools

- `get_organization_entity`: Schema.org Organisation graph data
- `get_founder_entity`: Schema.org Person graph for founder Vince Baker
- `query_knowledge_hub_node`: Search semantic lattice links and atomic answer blocks
- `get_service_module`: Technical specs and commercial blueprint parameters
